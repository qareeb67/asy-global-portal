# ASY Global Travel & Mobility — V1.5.9 UI Pass

This release applies the approved ASY & Hajja Zainab visual direction to the private operations portal.

Highlights:
- Homepage-inspired hero treatment with the approved artwork style.
- African/global destination cards using the approved visual artwork.
- Five-item trust strip.
- Warm cream, deep navy, teal and gold palette.
- Refined operations statistics and lower information panels.
- Existing client, document, payment, opportunity, notification and receipt workflows preserved.
- Payment receipt/new-tab work from the V1.5.8 patch retained.

Run from the project root:
`npm run install:all`
then:
`npm run dev`
